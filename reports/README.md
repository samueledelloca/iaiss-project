# reports/ — the 20-page PhD report

`main.tex` is the report. Tables and value-macros under `tables/` and
`generated_values.tex` are produced from the actual results by
`scripts/make_report_assets.py`, so every number matches the computed output.

## Build

```bash
./run.sh report          # regenerate assets + compile main.pdf
```

Compiles with **pdflatex** (TeX Gyre Heros). Roboto (the preferred font) needs a
working `fontspec` engine; this machine's `luaotfload` is not installed, so the
committed PDF uses the closest available sans. To use Roboto, install a working
lualatex/xelatex and switch the font block in `main.tex` to `\setmainfont{Roboto}`
(the alternative preamble is documented in the file).

Figures are generated by `scripts/reproduce_figures.py` into `reports/figures/`.
